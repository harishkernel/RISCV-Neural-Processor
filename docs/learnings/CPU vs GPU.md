# CPU vs GPU

## Overview

- Both CPUs and GPUs are programmable processors. At a high level, they perform the same cycle:

```text
Read Data → Execute Instruction → Write Result
```

### CPU
- 5 highly powered cores

### GPU
- 1000+ normal cores
